Ciutkan

Ukuran file mengecil, resolusi tetap utuh.

Unggah video atau tempel tautannya. Ciutkan menurunkan bitrate, bukan jumlah piksel, jadi gambar tetap berukuran sama. Semua diproses di browser Anda, video tidak dikirim ke server.

Sumber video

Harus tautan langsung ke file video, dan server sumbernya harus mengizinkan akses dari browser (CORS). Jika gagal, unduh dulu lalu unggah manual.

Tingkat kompresi

Resolusi dan frame rate tidak diubah. Proses berjalan di perangkat Anda, jadi video besar bisa lama dan memakan memori. Biarkan tab tetap terbuka sampai selesai.

Memulai…

  1. Membaca file
  2. Menyiapkan mesin kompres
  3. Membaca info video
  4. Mengompres
  5. Selesai
